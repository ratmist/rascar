# Кейс 2. Оператор зала

Оцените состояние каждого заданного стола: сколько людей, рук, чашек, посуды и личных вещей видно рядом с ним. Готовый детектор и соседние кадры помогут начать без GPU. Для более сильного решения пригодятся изображения, пространственная привязка и временной контекст.

Полное условие и правила — в `TASK.md`. Состав текущей версии — в `data_card.json`.

## Быстрый старт

Python 3.12 проверен организатором. Из папки пакета:

```bash
python -m pip install -r requirements.txt
python check_data.py --data .
python baseline.py --data . --mode detector --validate
python baseline.py --data . --mode detector --out submission.csv
python preview.py --data . --submission submission.csv --out preview.jpg
```

`preview.jpg` показывает прогнозы на нескольких активных тестовых кадрах. `preview.csv` содержит очередь подсказок оператору. Это прогнозы и простые правила поверх них, а не скрытый эталон.

## Три стартовых подхода

- `--mode median`: медианные train-счётчики, без анализа изображения.
- `--mode detector`: геометрическая привязка прод-детекций к одному столу. Для вещей выдаёт ноль.
- `--mode calibrated`: поправки к прод-счётчикам, модель вещей и занятости на открытом train.

Сначала проверяйте модель с `--validate`: обучение идёт на 25 октября UTC, проверка — на 26 октября. Затем запускайте без флага для обучения на всём train и создания тестового сабмита. Фиксированные настройки бейзлайна не гарантируют улучшения на каждом классе или сплите.

Локальный пересчёт собственной валидации:

```bash
python score.py validation_labels.csv validation_submission.csv --details
```

Ключ должен содержать только строки вашей валидации; сабмит — ровно те же `row_id`. Для ключей с `Usage` утилита дополнительно печатает Public и Private и исключает `Ignored`.

`baseline.ipynb` содержит такой же запуск для Jupyter/Kaggle. Если при подключении архив остался ZIP-файлом, сначала распакуйте его в рабочую папку и укажите путь к ней. Во время запуска никаких весов или внешних данных не скачивается.

## Где искать улучшения

Сравните полный кадр и расширенный crop стола; учитывайте человека за дальней границей столешницы; сопоставляйте рамки соседних кадров по геометрии, а не по номеру. Для посуды и вещей прод-детектора недостаточно. В `aux_frames.csv`, `aux_boxes.csv` и файлах `aux_*.jpg` есть дополнительные старые изображения с ручными боксами, с ограничениями, описанными в условии.
